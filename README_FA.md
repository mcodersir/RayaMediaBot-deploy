# ربات انتقال خبر تلگرام به کانال بله Raya Media

## اجرا در ویندوز

1. Python 3.11 یا جدیدتر را نصب کنید و گزینه Add Python to PATH را فعال کنید.
2. یک بار `setup.bat` را اجرا کنید.
3. سپس `run.bat` را اجرا کنید.
4. ربات بله باید در کانال `@rayamedia` ادمین باشد و اجازه ارسال پست/رسانه داشته باشد.

توکن تستی ارائه‌شده داخل فایل `.env` قرار داده شده است. بعد از تعویض توکن فقط مقدار `BALE_BOT_TOKEN` را در همان فایل عوض کنید.

## کانال‌های ورودی

- `@moghavematkhabar`
- `@khabarfuri`
- `@Naya_Press`

کانال‌ها از صفحه عمومی `https://t.me/s/<channel>` خوانده می‌شوند، بنابراین API ID/API Hash یا حساب تلگرام لازم نیست. اگر روی سیستم شما `t.me` مسدود است، در `.env` مقدار `TELEGRAM_HTTP_PROXY` را تنظیم کنید؛ HTTP و SOCKS5 پشتیبانی می‌شود.

## رفتار ربات

- لینک‌ها و شناسه‌های کانال‌های منبع حذف می‌شوند.
- `ج.ا` و صورت‌های مشابه به `جمهوری اسلامی ایران` تبدیل می‌شود.
- `جمهوری اسلامی` در صورت نداشتن `ایران` به `جمهوری اسلامی ایران` تبدیل می‌شود.
- آگهی‌های واضح، ناسزا و دعوت مستقیم به خشونت منتشر نمی‌شوند.
- خبرهای مشابه/تکراری بین منابع دوباره منتشر نمی‌شوند.
- خبرها به یکی از سه دسته `#Iran`، `#MiddleEast` و `#International` می‌روند.
- عکس و ویدیو تا سقف امن 49MB دریافت و در بله آپلود می‌شوند؛ در صورت خطای متد رسانه، `sendDocument` به‌عنوان fallback استفاده می‌شود.
- هر 30 دقیقه حداکثر 10 خبر منتشرشده اخیر با خلاصه‌ساز TextRank محلی و بدون API هوش مصنوعی جمع‌بندی می‌شوند.
- در اولین اجرا فقط 3 پست آخر هر کانال بررسی می‌شود تا کانال بله با آرشیو قدیمی پر نشود. این مقدار در `config.json` قابل تغییر است.

## تنظیمات

تنظیمات عمومی در `config.json` و تنظیمات محرمانه/محیطی در `.env` هستند.

فایل دیتابیس: `data/rayamedia.sqlite3`

لاگ: `logs/rayamedia.log`

برای تست اتصال بله و تلگرام: `diagnose.bat`

برای اجرای تست‌های داخلی پروژه: `test.bat`

V9: مدیریت کامل‌تر پنل، دکمه‌های شیشه‌ای سبک، کنترل از راه دور بدون نیاز به حضور سیستم.

## اجرای رایگان ابری

برای استقرار، `Dockerfile` و `render.yaml` آماده‌اند. متغیرهای `BALE_BOT_TOKEN`،
`ADMIN_ID` و `ADMIN_PASSWORD` را فقط در بخش Environment سرویس وارد کنید و هرگز
فایل `.env` را commit یا upload نکنید. مسیر `/health` برای health check ساخته شده
است.

هشدار: پلن رایگان سرویس‌های ابری ممکن است sleep/restart و فایل‌سیستم موقت داشته
باشد؛ دیتابیس SQLite برای کارکرد همان instance مناسب است، اما برای ماندگاری
بلندمدت باید datastore جداگانه تنظیم شود.
